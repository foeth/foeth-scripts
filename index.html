02 / Install

How to install

Takes a couple of minutes. Close After Effects before installing.

Scripts · .jsx / .jsxbin

ScriptUI
  1. Download the archive and unzip it.
  2. Windows: copy the file to Adobe After Effects [version]/Support Files/Scripts/ScriptUI Panels
  3. Mac: copy it to Applications/Adobe After Effects [version]/Scripts/ScriptUI Panels
  4. In AE go to Edit → Preferences → Scripting & Expressions and enable “Allow Scripts to Write Files and Access Network”.
  5. Restart AE and open the panel from the Window menu.

Plugins · .aex / .plugin

Effects
  1. Download the archive and unzip it.
  2. Windows: copy the .aex to C:/Program Files/Adobe/Common/Plug-ins/7.0/MediaCore
  3. Mac: copy the .plugin to /Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore
  4. Restart After Effects.
  5. Find the effect under Effect → FOETH.
