# FOETH Scripts: сайт

Одностраничный сайт с каталогом бесплатных плагинов и скриптов для After Effects.

## Структура

```
foeth-scripts/
├── index.html     ← весь сайт (дизайн, каталог, логика)
├── files/         ← сюда кладёшь архивы для скачивания (.zip)
└── previews/      ← сюда кладёшь превью (.gif / .mp4 / .jpg)
```

## Как добавить новый инструмент

1. Положи архив в `files/`, например `files/my-tool.zip`.
2. Если есть превью, положи его в `previews/`, например `previews/my-tool.mp4`
   (mp4 весит в 5–10 раз меньше gif, поэтому лучше он).
3. Открой `index.html`, найди `const TOOLS = [` и скопируй любой блок `{ ... }`.
4. Поменяй поля:
   - `id`: короткое уникальное имя латиницей
   - `type`: `"plugin"` или `"script"`
   - `title`, `desc`, `features`: название, описание, список возможностей
   - `version`, `ae`, `format`, `size`
   - `file`: путь к архиву, например `"files/my-tool.zip"`
   - `preview`: путь к превью или `""` (тогда нарисуется абстрактная заставка)
   - `isNew`: `true`, чтобы показать метку NEW
   - `date`: дата в формате `"2026-11-13"`

Счётчики на сайте пересчитываются сами.

## Что заменить на свои данные

Поиском по `REPLACE WITH YOUR LINKS` найдёшь места с:
- ссылками на донаты (PayPal, Patreon)
- ссылками на соцсети (TikTok, Telegram)

Донаты выводятся через PayPal: Ko-fi переводит деньги сразу на твой PayPal,
Patreon выплачивает через PayPal или Payoneer. Buy Me a Coffee не подходит,
с 2024 года он не делает выплаты в Украину.

Ненужную кнопку можно просто удалить целиком (весь тег `<a ...>…</a>`).

## Бесплатная публикация через Netlify (самый простой способ)

1. Зайди на https://app.netlify.com/drop
2. Перетащи туда всю папку `foeth-scripts`.
3. Через несколько секунд сайт будет доступен по ссылке вида `xxx.netlify.app`.
   После регистрации адрес можно поменять, например на `foeth.netlify.app`.

## Бесплатная публикация через GitHub Pages

1. Создай репозиторий на GitHub и загрузи туда содержимое папки.
2. Settings → Pages → Branch: `main` → Save.
3. Сайт откроется по адресу `username.github.io/repo-name`.

Ограничение: файл в GitHub не может быть больше 100 МБ. Если плагин весит больше,
загрузи его в GitHub Releases или на Google Drive и вставь в `file` прямую ссылку.

## Свой домен

Купи домен (например `foeth.dev` или `foeth.ru`, это примерно 10–15 $ в год)
и подключи его в настройках Netlify или GitHub Pages (раздел Domain / Custom domain).
